# Calculator

A simple calculator web application built with HTML, CSS, and JavaScript.

## 📖 Description

A basic calculator application that performs arithmetic operations like addition, subtraction, multiplication, and division.

## 🔗 Live Website

**[Visit the Calculator](https://nikhil-raikar.github.io/Calculator/)**

## 🛠️ Technology Stack

- HTML5
- CSS3
- JavaScript

## 🚀 Features

- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Clean and intuitive user interface
- Real-time calculation display
- Responsive design

## 📁 Project Structure

```
Calculator/
├── index.html          # Main HTML file
├── style.css           # Styling
├── script.js           # JavaScript logic
└── README.md           # This file
```

## 💡 How to Use

1. Visit the live website link above, or
2. Clone the repository and open `index.html` in your browser
3. Enter numbers and select an operation
4. Click the equals button to get the result

## 📝 Installation (Local)

```bash
# Clone the repository
git clone https://github.com/Nikhil-Raikar/Calculator.git

# Navigate to the project directory
cd Calculator

# Open index.html in your browser
```
